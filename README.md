# 바이브코딩 해커톤 - 팀 발표

## 1. 팀명 / 팀원

- 팀명: 2팀
- 팀원: 이상각, 강태훈

---

## 2. 한 줄 소개

> 모임이나 행사에서 사용할 수 있는 랜덤 게임과 팀 배정 기능을 하나로 제공하는 미니게임 웹 서비스 **LUCKY PLAY**

---

## 3. 선정 이유 / 해결하려 한 문제

> 모임이나 행사에서 자리 뽑기, 팀 나누기, 룰렛, 사다리타기 등을 진행할 때 각각 다른 서비스를 사용해야 하는 불편함이 있었습니다.  
> 이를 해결하기 위해 참가자 명단을 한 번만 등록하면 여러 게임에서 공통으로 사용할 수 있는 웹 서비스를 제작했습니다.

---

## 4. 핵심 기능

- 기능 1: 참가자 명단 등록 및 관리
- 기능 2: 번호·이름 랜덤 뽑기
- 기능 3: 참가자 랜덤 룰렛
- 기능 4: 완전 랜덤 / 남녀 균형 팀 자동 나누기
- 기능 5: 랜덤 미션 뽑기
- 기능 6: 사다리타기
- 기능 7: 사다리 결과 직접 입력 및 이동 애니메이션
- 기능 8: 참가자 정보를 여러 게임에서 공통으로 사용

---

## 5. 사용 기술 스택

- Frontend: React, JavaScript
- Build Tool: Vite
- Styling: CSS
- Storage: LocalStorage
- Version Control: Git, GitHub
- Deployment: Netlify
- AI Tool: GitHub Copilot

---

## 6. AI 활용 포인트

> GitHub Copilot을 활용하여 기존 LUCKY PLAY 프로젝트의 코드를 분석하고 기능 개선 및 오류 수정 작업을 진행했습니다.

- 기존 프로젝트 코드 구조 분석
- 팀 자동 나누기 로직 개선
- 남녀 균형 배정 기능 보완
- 사용자 입력 예외 처리 보완
- 게임 실행 중 발생할 수 있는 오류 점검
- 기존 디자인과 기능을 유지하면서 코드 개선
- Git 브랜치와 Pull Request를 이용해 기존 버전과 개선 버전을 분리하여 관리

- 참가자 명단을 공통으로 사용

- Pull Request를 생성하여 기존 버전과 개선 내용을 비교

## 10. 결과 및 느낀 점

> 단순히 AI에게 새로운 프로그램을 만들어 달라고 요청하는 것보다, 기존 프로젝트를 AI가 분석하도록 하고 필요한 부분만 수정하도록 구체적으로 지시하는 것이 중요하다는 점을 확인했습니다.

> 또한 AI가 생성한 코드도 그대로 사용하는 것이 아니라 실제 실행, 빌드, Git 변경사항 등을 직접 확인하면서 검증해야 안정적인 결과를 얻을 수 있었습니다.
