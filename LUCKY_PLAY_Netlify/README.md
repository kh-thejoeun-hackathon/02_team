# LUCKY PLAY

모임에서 참가자 명단을 한 번 등록하고 여러 미니게임을 함께 사용하는 React 프로젝트입니다.

## 포함 기능

- 번호·이름 뽑기: 도착한 사람이 이름을 터치하거나 순서대로 진행
- 전체 뽑기 수·뽑은 수·남은 수·꽝 개수·남은 꽝 표시
- 3·2·1 게임 시작, 번호 회전, 당첨 축하·꽝 전용 효과
- 이번 차례 넘기기
- 추첨 연출 0.75초
- 룰렛, 팀 자동 나누기, 랜덤 미션, 사다리타기
- 참가자 명단 및 자리 결과 자동 저장(localStorage)
- 모바일 반응형 화면
- Netlify 새로고침 404 방지
- 예시 이름 없이 `이름을 입력하세요` 안내만 표시
- 최대 100명 등록 및 전체 뽑기 수 100개 지원
- 숫자 입력값을 모두 지운 뒤 새 값 입력 가능
- 메인 버튼 및 명단 화면을 `모임장 명단관리`로 표기
- 첫 접속은 0명·빈 명단·자리 수 0으로 시작
- 전체 자리 수와 입력 이름 수를 실시간 비교하고, 많음·모자람을 각각 안내
- 두 인원수가 정확히 일치할 때만 명단 등록

## 로컬 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## Netlify 배포

Git 저장소로 배포하면 `netlify.toml` 설정이 자동 적용됩니다.

- Build command: `npm run build`
- Publish directory: `dist`

수동 배포는 `npm run build` 후 생성되는 `dist` 폴더를 Netlify Deploys 화면에 올리면 됩니다.
