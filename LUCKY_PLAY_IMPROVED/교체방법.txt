LUCKY_PLAY_Netlify 프로젝트에서 아래 2개 파일만 교체하세요.

1. src/App.jsx
2. src/style.css

추가/변경 기능
- 모임장 명단관리: 남성 / 여성 / 선택 안 함(기본값)
- 성별 정보는 선택사항
- 팀 나누기: 완전 랜덤 / 남녀 균형
- 선택 안 함 참가자는 팀 인원이 적은 곳부터 랜덤 배정
- 성별 정보가 전혀 없으면 자동 완전 랜덤
- 팀 결과에 남/여/미선택 숫자 표시
- 기존 사다리 15단, 결과 직접입력, 네온 경로, 지렁이 이동, 효과음 유지

교체 후:
npm run build
npm run preview
